# Hyper-V Virtualization Lab

## Lab Objectives

- Enable Hyper-V on the host system

- Download an authentic Windows 11 ISO

- Verify the ISO's SHA-256 hash.
  
- Create a virtual machine
  
- Configure the virtual machine's TPM for Windows 11
